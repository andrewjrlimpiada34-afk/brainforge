# **App Name**: BRAINFORGE

## Core Features:

- User Authentication & Profile: Secure user registration, login, logout, and display of core profile information including username, level, and XP. This also includes storing user data securely.
- Core Training Game Modules: Implementation of foundational brain training games such as Pattern Recall (Memory) and Number Sequences (Logic) with interactive play modes.
- Dynamic Difficulty & Scoring: An adaptive system to automatically adjust game difficulty based on user performance and calculate scores considering accuracy, speed, and difficulty level.
- XP, Leveling & Progress System: Award experience points (XP) after each game, manage player levels based on accumulated XP, and track overall progress.
- Daily Challenge Generation: Dynamically generate daily tasks for users, rewarding bonus XP upon completion to encourage consistent engagement.
- Progress Dashboard & Leaderboards: Display a personalized dashboard with performance graphs, a cognitive stats radar chart, and global leaderboards to showcase user rankings.
- Personalized AI Feedback: A generative AI tool that analyzes user game performance across cognitive areas and provides tailored feedback and suggestions for improvement.

## Style Guidelines:

- Primary interactive color: Vibrant green (#1AE55A) for an energetic and growth-oriented feel against a dark background. This color provides a digital, scientific tone without being overly aggressive.
- Background color: Very dark, desaturated green (#0A100C) to maintain a cohesive dark theme that minimizes eye strain and allows vibrant elements to pop.
- Accent color: Bright lime green/yellowish green (#BBF33E) used for highlights, calls to action, and distinct visual elements, offering good contrast and enhancing interactivity.
- Body and headline font: 'Space Grotesk' (sans-serif) for its modern, techy, and slightly futuristic aesthetic, fitting the brain training app's digital nature, suitable for headlines and short body texts.
- Use sleek, abstract vector icons related to cognitive functions (e.g., stylized brains, gears, lightning bolts) and gamified achievements (e.g., stars, shields, medals). The icons should be minimalistic and align with the modern, digital interface.
- Utilize a responsive, card-based layout for clear content separation on both desktop and mobile views. The dashboard should feature well-organized modules for stats, daily goals, and game selection, optimized for intuitive navigation in a dark mode environment.
- Implement subtle, fluid animations for UI transitions, game state changes, and feedback elements (e.g., progress bar filling, XP/score count-ups, and hover effects). Animations should enhance user engagement without being distracting or slowing down performance, especially in reaction-based games.
